# CaboSystems Field Service

Sistema de gestión para servicios de campo de CaboSystems. Incluye una app móvil con React Native/Expo y soporte offline, check-in con GPS y fotos, además de un dashboard web con Next.js para supervisión de proyectos en tiempo real. El backend está impulsado por Supabase (PostgreSQL).

## Descripción

La solución permite coordinar actividades del personal técnico en campo, registrar evidencias, supervisar avances y mantener la información sincronizada incluso cuando el usuario está sin conexión.

## Stack principal

- React Native / Expo
- Next.js
- Supabase
- PostgreSQL
- Tailwind CSS
